VanSwap Documentation

Complete guide to using VanSwap - The lightest, fastest DEX on Vana Chain. Learn how to swap tokens, provide liquidity, and build on our protocol.

What is VanSwap?

VanSwap is a decentralized exchange (DEX) built on Vana Chain, featuring:

  • Zero-lag trading experience
  • Ultra-low gas fees
  • Uniswap V2 proven router
  • Maximum security for funds and data
  • Simple, intuitive interface

🚀 Features

Swap

Instant token swaps with minimal slippage and competitive rates.

  • Real-time price feeds
  • Low 0.25% trading fee
  • Multi-hop routing for better prices
  • Slippage tolerance settings

Liquidity Pools

Provide liquidity and earn trading fees from swaps.

  • Add liquidity to existing pools
  • Create new token pairs
  • Earn 0.25% fee from all trades
  • Manage your LP positions

Yield Farming

Stake your LP tokens to earn VANS rewards.

  • Stake LP tokens to farm VANS
  • Competitive APY returns
  • Multiple farming pools
  • Auto-compounding options

Create Token

Launch your own VRC-20 tokens in minutes.

  • No coding required
  • Instant deployment
  • Custom token parameters
  • Initial liquidity setup
