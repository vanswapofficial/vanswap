📋 How to Use Batch Transfer

  1. Select Network: Choose between VANA Network or 0G Network
  2. Connect Wallet: Connect your Web3 wallet (MetaMask, Trust Wallet, etc.)
  3. Enter Token Address: Paste your ERC20 token contract address
  4. Add Recipients: Manually add addresses or upload CSV file
  5. CSV Format: address,amount (no headers needed)
  6. Validate: Click "Validate Transfers" to check for errors
  7. Execute: Confirm and execute batch transfer

💡 Tip: Batch transfers can save up to 70% in gas fees compared to individual transfers.
